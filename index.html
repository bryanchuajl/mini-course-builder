If Statement

Programs often need to check whether something is true before doing something about it. An if statement does exactly that: it tests a condition, and runs its action only when the condition is true. When the condition is false, Python skips the action and carries on below.

Try this code:

a = 7
if a < 10:
    print('a is less than 10')

Output:

a is less than 10

Here a < 10 is the condition. Because 7 is less than 10, the condition is true, so the indented print line (the action) runs. If a were 12, nothing would be displayed.

Indentation matters

Python uses indentation (the spaces at the start of a line) to work out which lines belong together. This is not optional. The indented lines under an if are the ones that only run when the condition is true.

If you remove the indentation, Python cannot tell what belongs to the if:

a = 7
if a < 10:
print('a is less than 10')

This produces an error:

IndentationError: expected an indented block after 'if' statement on line 2

Comparison Operators

The condition in an if statement is usually a comparison. A comparison operator compares two values and gives back a Boolean result, which is either True or False.

OperatorMeaningExample
<Less thana < b
>Greater thana > b
<=Less than or equal toa <= b
>=Greater than or equal toa >= b
==Equal toa == b
!=Not equal toa != b

Note that "equal to" is written with two equals signs. A single = is used to store a value in a variable, while == asks whether two values are the same.

Elif and Else Statements

An if statement on its own handles one possibility. To handle more, add elif (short for "else if") and else:

  • elif checks another condition, but only if every condition before it was false.
  • else holds the final actions, which run only if every condition before it was false.

Python works down the list from the top and runs the first block whose condition is true. Once it has run one block, it skips the rest.

a = int(input('Input a number: '))
if a < 10:
    print('It is less than 10')
elif a > 10:
    print('It is more than 10')
else:
    print('It is equal to 10')

Run this code three times, entering 7, 15 and then 10. You should see:

  • 7 displays It is less than 10
  • 15 displays It is more than 10
  • 10 displays It is equal to 10 (neither condition was true, so else ran)

Practice

Write code that asks the user to respond to the statement "SEG has 8 diplomas. True or False?". If they enter True, display You are correct. If they enter False, display You are wrong. For anything else, display Invalid response.

One answer:

userinput = input('SEG has 8 diplomas. True or False?')
if userinput == 'True':
    print('You are correct')
elif userinput == 'False':
    print('You are wrong')
else:
    print('Invalid response')

Further practice: ignoring upper and lower case

The code above only accepts exactly True or False. Typing true or TRUE gives "Invalid response". How could you make the input case insensitive, so that any capitalisation is accepted?

Hint: use lower() or upper(). Convert what the user typed to one case first, then compare it with text in that same case:

userinput = input('SEG has 8 diplomas. True or False?')
if userinput.lower() == 'true':
    print('You are correct')
elif userinput.lower() == 'false':
    print('You are wrong')
else:
    print('Invalid response')

Using upper() works equally well, as long as you compare with 'TRUE' and 'FALSE'.

Logical Operators

Sometimes one comparison is not enough. Logical operators combine conditions and give back a Boolean result (True or False).

OperatorWhat it doesExample
andTrue only if both conditions are truea > 0 and b > 0
orTrue if at least one condition is truea > 0 or b > 0
notFlips the result, so true becomes false and false becomes truenot(a > 0)

Summary

In this lesson you learned four connected ideas:

  • If statement: runs an indented block of code only when a condition is true.
  • Comparison operators: <, >, <=, >=, == and != compare two values and give True or False.
  • Elif and else statements: let one program choose between several possibilities, running only the first block that matches.
  • Logical operators: and, or and not combine conditions into one result.
